# نظام متابعة العملاء والتسعير — نسخة مستقلة (Standalone)

أداة ويب كاملة تعمل من غير أي سيرفر خلفي أو اشتراك أو إنترنت. كل البيانات (العملاء، الاختيارات، الإعدادات، الفريق) تُحفظ بشكل دائم داخل متصفحك على جهازك (IndexedDB).

## مبدأ العمل: مصدر واحد للحقيقة

المقايسة (Excel)، العقد (Word)، والعرض التقديمي (PowerPoint) **لا تُحفظ كملفات منفصلة قابلة للتعديل مستقلة عن النظام** — هي مُولَّدة مباشرة من بيانات العميل الحالية في كل مرة تضغط "تحميل". يعني لو غيّرت مستوى تشطيب أو مساحة الشقة، وصدّرت الملفات تاني، هتيجي محدَّثة تلقائيًا. الحل الوحيد الصحيح تقنيًا لمشكلة "الملفات بتطلع مختلفة عن بعض" هو إلغاء فكرة الملفات المستقلة تمامًا واعتبار النظام هو المصدر الوحيد — وهو بالظبط اللي معمول هنا.

**ملاحظة مهمة:** التعديل اليدوي على ملف Excel أو Word أو PowerPoint بعد تصديره **لن ينعكس على النظام** — العلاقة اتجاه واحد (من النظام للملف)، مش مزامنة ثنائية. أي تعديل نهائي لازم يتم من داخل النظام نفسه.

## فريق المكتب والصلاحيات

### الوضع المحلي (بدون مزامنة سحابية)
- أول مرة تفتح الأداة، بتنشئ حساب "مالك المكتب".
- من تبويب "الإعدادات"، مالك المكتب يضيف أعضاء الفريق يدويًا بالاسم.
- **تنويه:** ده تنظيم لتسهيل المتابعة على جهاز واحد فقط، وليس حماية أمنية حقيقية — أي شخص يفتح نفس الجهاز يقدر يوصل لكل البيانات.

### وضع المزامنة السحابية
- كل شخص بيسجّل حسابه بنفسه (بريد إلكتروني وكلمة سر حقيقيين عبر Supabase Auth).
- **الدور (مالك/مهندس) لا يُختار من الشخص نفسه أبدًا.** أول من يسجّل في المشروع يصبح "مالك المكتب" تلقائيًا (من خلال Trigger في قاعدة البيانات، وقت التسجيل، قبل ما أي كود في المتصفح يشتغل). أي شخص يسجّل بعد كده يظل بحالة **"بانتظار الموافقة"** ولا يقدر يوصل لأي بيانات (السياسات الأمنية على قاعدة البيانات نفسها بتمنعه، مش بس واجهة الاستخدام) لحد ما مالك مكتب فعلي يوافق عليه من تبويب الإعدادات.
- التحقق من الدور يتم بالكامل من الخادم (Postgres Row Level Security) — حتى لو حد فتح أدوات المطوّر وحاول يستدعي الـ API مباشرة، مش هيقدر يغيّر دوره لنفسه أو يشوف بيانات قبل الموافقة.

**نصيحة أمان:** لا تشارك رابط ومفتاح مشروع Supabase إلا مع فريق مكتبك، ولو حصل وشوفت طلب انضمام في "الإعدادات" مش عارف مين صاحبه، ارفضه (متوافقش عليه) وغيّر كلمة سر حسابك على الأقل.

## محتويات المجلد

```
public/
  index.html   ← افتح هذا الملف مباشرة بالنقر المزدوج لتشغيل الأداة
  bundle.js    ← الكود (React + كل المكتبات مُدمجة بداخله)
  styles.css   ← التنسيقات
src/
  App.jsx      ← الكود المصدري الأصلي (لو حبيت مبرمج يعدّل عليه لاحقًا)
  main.jsx
  tailwind-input.css
```

## طريقة التشغيل — بدون إنترنت وبدون أي إعداد

**افتح ملف `public/index.html` مباشرة بالنقر المزدوج.** تم اختبار هذا فعليًا ويعمل بشكل كامل بدون تشغيل أي خادم أو الاتصال بالإنترنت.

## الاستضافة على الإنترنت (اختياري)
ارفع محتويات مجلد `public/` فقط على Netlify Drop (https://app.netlify.com/drop) أو GitHub Pages أو أي استضافة ملفات ثابتة.

## الملفات التي تُصدَّر من النظام — بتنسيق احترافي حقيقي، ومولّدة لحظيًا

- **المقايسة (Excel)**: `.xlsx` حقيقي، مقسّمة لفئات (تصميم / تعديلات معمارية / تشطيبات / كهرباء / سباكة / فرش) بعناوين ملوّنة وإجمالي فرعي لكل فئة، بالإضافة لعمود "المواصفة المقترحة" (نوع الدهان، نوع المفاتيح، نوع التكييف... إلخ حسب المستوى المختار).
- **العرض التقديمي (PowerPoint)**: `.pptx` من 4 سلايدات — غلاف، المستوى المختار لكل نطاق عمل، لوحة خامات استدلالية (Mood Board) للمستويات الفعلية المختارة لهذا العميل، وملخص السعر النهائي.
- **العقد (Word)**: `.docx` حقيقي بعناوين ملوّنة وجدول دفعات منسّق، يظهر تلقائيًا للتحميل بمجرد وصول العميل لمرحلة "تم التعاقد".

## نقطة مهمة عن حفظ البيانات

البيانات محفوظة داخل **متصفح معين على جهاز معين** (IndexedDB). من تبويب "الإعدادات"، اضغط "تصدير نسخة احتياطية" بشكل دوري واحتفظ بالملف (JSON) في مكان آمن. لاسترجاعها على أي جهاز، استخدم "استيراد نسخة احتياطية".

## خارطة الطريق — من أداة محلية إلى برنامج مكتب حقيقي

الأداة الحالية Local-first بالكامل. لو المكتب كبر واحتاج:
- وصول متزامن من عدة أجهزة/فروع في نفس الوقت
- صلاحيات حقيقية محمية بكلمة مرور لكل مهندس
- سجل تعديلات (من غيّر السعر ومتى)
- عدم الاعتماد على جهاز واحد كنقطة فشل وحيدة

فالخطوة التالية الطبيعية هي تحويل طبقة التخزين (دوال `storageGet/storageSet/storageListKeys/storageDelete` في أعلى `App.jsx`) من IndexedDB محلي إلى قاعدة بيانات حقيقية مثل Supabase أو Firebase (لهما مستوى مجاني كافٍ لمكتب صغير/متوسط)، مع إضافة مصادقة دخول حقيقية بدل اختيار الهوية الحالي. الواجهة نفسها (كل الشاشات والحسابات) لن تحتاج إعادة كتابة تقريبًا لأن طبقة البيانات معزولة عن طبقة العرض من البداية.

## لو حبيت تطوير الكود لاحقًا

```
npm install
npx esbuild src/main.jsx --bundle --minify --outfile=public/bundle.js --platform=browser
npx @tailwindcss/cli -i src/tailwind-input.css -o public/styles.css --minify
```
